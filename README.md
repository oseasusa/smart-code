- Identificador SPDX: `LicenseRef-SmartCode-1.0`

## Como aplicar a um projeto

1. Copie o arquivo `LICENSE` para a raiz do projeto.
2. Coloque no topo de cada arquivo de código:

```
Copyright (c) 2026 Oseas Matos Soares. Todos os direitos reservados.
SPDX-License-Identifier: LicenseRef-SmartCode-1.0
```

3. Formalize cada cliente com um Contrato de Licenciamento (Anexo C).
